Dovakarn fork of Community Shaders
==================================

Changes by the Dovakarn team (first made 2026-10-18), all on branch dovakarn/perf. They change no
picture: each only removes main-thread work. Each can be switched off without a rebuild in
Data\SKSE\Plugins\CommunityShaders_Dovakarn.ini, section [Perf] (missing file or key = on):

- ParticleLightShaderGate  (src/Features/LightLimitFix.cpp, CheckParticleLights)
  The particle-light test now looks at the pass's shader first and stops for any pass not drawn
  by the effect shader, instead of reading every pass's (cold) shader property. Only effect-shader
  passes can carry a particle light, so the result is the same for every pass.

- PrefetchNextPass  (src/Features/LightLimitFix.cpp, BSBatchRenderer_RenderPassImmediately)
  While a render pass is drawn, the next pass's shader property and geometry, and the pass after
  that, are prefetched into the CPU cache, so the next draw does not wait on memory.

- PrefetchPassObjects  (src/Features/LightLimitFix.cpp, BSBatchRenderer_RenderPassImmediately)
  At the start of each render pass, the objects the engine reads later in that pass (the mesh's
  renderer data, the material, the alpha property, the skin instance) are prefetched.

- LogParticleLights (debug, off by default)  (src/Features/LightLimitFix.cpp, AddParticleLightsToBuffer)
  Logs how many particle lights were queued per frame, averaged over 600 frames.

- ProfilerOnlyWhenVisible  (src/Profiler.*, src/State.cpp Reset)
  The built-in pass profiler (GPU timestamp queries and per-frame statistics) runs only while the
  Community Shaders menu or overlay is open, or frame annotations are on. Its numbers are only
  shown there.

Switch file reader: src/DovakarnPerf.h, loaded in src/XSEPlugin.cpp.

Menus closed for online play (2026-10-19, branch dovakarn/menus on top of dovakarn/perf; src/DovakarnMenus.h).
No switch: Dovakarn is an online game where no player may turn features off or edit weather and fog to see
further than others, and a switch in a file on the player's PC would be one every player could flip.
- The menu never opens: its menu key (src/Menu.cpp, ToggleKey action) and the built-in Shift+Enter do nothing,
  and Shift+Enter goes on to the game like any other key.
- The CS Editor (weather, lighting, fog) never opens: EditorWindow::CanBeOpen answers false, and every way in (its
  key, the menu's button, EditorWindow::OpenWeatherFeatureSetting) asks it first.
- The first-start dialog never shows (HomePageRenderer::ShouldShowFirstTimeSetup answers false).
- Remote Control does not register its tools with a devbench host (src/Features/RemoteControl.cpp DataLoaded).
- Unchanged: the effects key (all effects on or off) and the performance overlay, which takes no input while the
  menu is closed.
To use the menu or the editor while developing, load the official DLL instead.
